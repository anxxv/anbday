# Приглашение на день рождения 🎀

Интерактивный сайт-приглашение в виде «книжки» с перелистыванием страниц.

## Структура файлов

```
index.html      — страницы сайта (экран имени/пола + все страницы книги)
style.css       — все стили и анимации
script.js       — логика перелистывания, подстановки имени и отправки формы
server.py       — сервер (только стандартная библиотека Python 3)
assets/         — все картинки
data/           — сюда сервер сохраняет ответы гостей (создаётся автоматически)
```

## Как запустить

1. Убедитесь, что установлен Python 3 (обычно уже есть на Mac; на Windows —
   скачать с python.org).
2. Откройте терминал в этой папке и выполните:

   ```
   python3 server.py
   ```

   (на Windows иногда команда называется просто `python server.py`)

3. Откройте в браузере адрес:

   ```
   http://localhost:8000
   ```

4. Чтобы гости могли открыть сайт со своих телефонов, компьютер с сервером
   должен быть доступен по сети — либо через локальную Wi-Fi сеть (тогда
   вместо localhost нужно использовать IP компьютера в этой сети), либо
   разместить эти же файлы на любом хостинге, который поддерживает Python
   (например Render, Railway, PythonAnywhere и т.п.). Файлы можно
   загрузить как есть — специальной настройки не требуется, достаточно
   команды `python3 server.py`.

   Если сайт публикуется на настоящем хостинге, там обычно нужно слушать
   порт, который задаёт сама платформа — сервер уже это умеет: он берёт
   порт из переменной окружения `PORT`, если она задана, иначе использует
   8000.

## Где смотреть ответы гостей

После того как гости начнут заполнять форму в конце сайта, в папке
`data/` появятся два файла:

- **`data/guests.json`** — самое удобное: список подтверждённых имён
  (`confirmed`) и список тех, кто не сможет прийти (`declined`). Если
  гость отправит форму повторно, его старый ответ в списке заменится
  новым.
- **`data/responses.json`** — полный журнал вообще всех отправленных
  ответов с датой и временем, на случай если нужна полная история.

Оба файла — обычный текст (JSON), их можно открыть даже в блокноте.

## Важно

- Пока сервер запущен, страницы, стили и картинки отдаёт именно он —
  просто открывать `index.html` двойным щелчком не стоит, потому что
  тогда форма обратной связи не сможет никуда отправить данные (нужен
  адрес `http://localhost:8000`, а не `file://...`).
- Имя и пол, введённые на первом экране, сохраняются в браузере
  гостя (localStorage), поэтому если он случайно обновит страницу —
  прогресс не потеряется.
- Для шрифтов сайт обращается к Google Fonts — для их загрузки нужен
  интернет у того, кто открывает сайт.
